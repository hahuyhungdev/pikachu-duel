# Pokémon tile sprites

These 64×64 battle sprites are bundled locally from the
[PokéAPI sprites repository](https://github.com/PokeAPI/sprites), using the
Generation III Emerald front-sprite set.

The catalog contains 48 species. The first 24 catalog IDs remain unchanged;
Quick uses 16 species, Classic 24, and Grand 48. Source files follow
`sprites/pokemon/versions/generation-iii/emerald/{national-pokedex-id}.png`.
All sprites are served locally, with no runtime request to PokéAPI.
